# Sentiment Analyzer

AI-powered Sentiment Analyzer built with React.js using OpenRouter API.

## Features
- Analyze text sentiment
- Detect Positive, Negative & Neutral tone
- Confidence score display
- Loading state handling
- Responsive UI
- Real-time result visualization

## Tech Stack
- React.js
- Tailwind CSS
- OpenRouter API

## Installation

```bash
npm install
npm run dev

VITE_OPENROUTER_KEY=your_api_key
